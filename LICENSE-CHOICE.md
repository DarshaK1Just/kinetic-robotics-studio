# Licensing checkpoint

The project contains original studio code and educational material as well as links to
third-party images, videos, libraries and open-source projects. No blanket MIT license is
asserted over these third-party materials. Review THIRD_PARTY_NOTICES.md, verify ownership
of the original work and select a license before accepting external contributions.

If you choose to publish this as open source, add an appropriate LICENSE for code and
separate educational-content / asset licensing disclosures.
